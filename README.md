# Camera Sharing App

A proposed privacy-first utility: borrow another phone's camera and receive the photos on your own phone, without app-created photos in the lender's system library.

**Current phase: planning only. No application implementation is authorized.**

- [Product and architecture planning pack](docs/README.md)
- [Shared engineering governance](docs/governance/README.md)
- [Codex instructions](AGENTS.md) · [Claude Code instructions](CLAUDE.md)

There are no app projects, dependencies, build/test commands or deployed services yet. Reading the Markdown files requires no setup. App prerequisites, pinned toolchains, setup/run/test commands and troubleshooting must be added with the first explicitly authorized implementation milestone; do not invent commands before they exist.

New contributors: read shared governance first, then the PRD, architecture, privacy specification, photo lifecycle and decision log linked from the planning pack. Select a task with explicit scope, acceptance evidence, an accountable role and the required review. Approval of these documents does not authorize M0 or any later development milestone.
